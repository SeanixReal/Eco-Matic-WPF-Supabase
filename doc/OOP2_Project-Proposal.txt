1. Introduction

    1.1 Project Overview

The "Eco-Matic" Simulator is a WinForms application built with C#. It promotes SDG 12
(Responsible Consumption) by integrating a standard vending machine with a unique
"trash-to-credit" recycling system, moving beyond the previous console version to a professional
GUI with persistent database connectivity.

    1.2 Objectives

     Develop an intuitive WinForms GUI for customer and admin interactions.
     Implement MySQL database persistence to replace csv.
     Simulate a "Recycle for Credit" module for sustainable waste management.
     Enforce role-based security via an authenticated administrator dashboard.

    1.3 Scope

The system includes a Customer UI for purchasing, recycling, and balance management, and
an Administrator UI for inventory CRUD (Create, Read, Update, Delete) and transaction
auditing.

2. System Analysis

    2.1 Problem Statement

The previous CLI version lacked user-friendly interaction and used prone-to-error CSV storage,
making data management and complex reporting difficult.

    2.2 Proposed Solution

A WinForms C#.NET application connected to MySQL will provide visual feedback, ensure data
integrity, and allow for efficient inventory and log management.
    2.3 Feasibility Study

     Technical: Reuses core OOP logic from OOP1 with new ADO.NET database handling.
     Operational: GUI significantly improves usability over command-line inputs.
     Financial: Uses free tools (Visual Studio Community, MySQL).
